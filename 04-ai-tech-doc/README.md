# 4. AI 활용 기술 문서

**요구 사항**: AI 도구 · 프롬프트 · 활용 내역 정리
**제출 형식**: PDF

## 들어갈 것

- [ ] `SIN_DIVE_AI활용.pdf` — 최종 제출본
- [ ] 원본 마크다운(`.md`)
- [ ] 실제로 쓴 프롬프트 원문 (요약이 아니라 **그대로**)

### 문서 구성

1. **사용한 AI 도구** — 코드 생성, 이미지 생성, 리깅/애니메이션, 사운드
2. **프롬프트** — 캐릭터 원화 생성에 쓴 프롬프트와 그 도달 과정
3. **활용 내역** — 어디에 AI를 썼고 어디를 사람이 판단했는지, 실패한 시도와 그 이유
4. **에셋 출처와 라이선스** — 외부 에셋(Spine 리그, BGM 등)의 원 저작자와 변경 고지

## 주의

- **실패 기록을 남기는 것이 이 문서의 값이다.** "AI로 만들었다"는 결과만 적으면
  심사자가 검증할 수 있는 것이 없다. 몇 번째 시도에서 무엇이 왜 안 됐는지가 근거다.
- 외부 에셋의 **변경 고지**(CC-BY 등)는 라이선스 의무다 — 레포의 `CREDITS`와
  내용이 어긋나지 않게 한다.
