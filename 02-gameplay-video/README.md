# 2. 플레이 동영상

**요구 사항**: 30~60초 플레이 영상
**제출 형식**: YouTube (링크)

## 들어갈 것

- [ ] 30~60초 플레이 영상 (길이 상한을 넘기지 않는다)
- [ ] YouTube 업로드 후 링크를 루트 [`README.md`](../README.md)의 링크 표에 기재
- [ ] 이 폴더에는 링크와 촬영 구성(어떤 장면을 몇 초에 담았는지)을 적어 둔다

## 주의

원본 영상 파일은 이 레포에 커밋하지 않는다 — 제출 형식이 YouTube 링크이고,
수십 MB짜리 바이너리는 클론을 무겁게 만든다. 필요하면 링크와 썸네일만 둔다.
