## 1. 한 줄 소개

> ### SIN DIVE (신 다이브)
>
> **"심연으로 내려갈수록 소녀들은 타락하지만, 그만큼 강해진다."**

지하 9,999층 '제로 프론티어'로 하강하는 요원들의 이야기입니다. **손가락을 위로 밀어
층을 내려가는 방치 RPG**와, **같은 층을 누가 더 빨리 쓸어내는지로 겨루는 실시간
2:2 PvP**를 한 게임 안에 담았습니다.

| | |
|---|---|
| 장르 | 숏츠형 방치 수집형 RPG + 실시간 PvP |
| 플랫폼 | **모바일 세로 웹** — 설치·로그인 없이 링크 하나로 실행됩니다 |
| 조작 | 터치 1점 — 탭과 위로 스와이프. 이동·조준·타겟팅이 없습니다 |
| 해상도 | 720 × 1280 고정 (PC는 레터박스) |
| 플레이 시간 | 싱글 = 무제한(방치) / PvP 1판 = 최대 120초 |
| 핵심 장치 | **타락도가 곧 공격력 배율** — 강해지려면 인간성을 내놓아야 합니다 |
| 플레이 링크 | **https://abyss.agenticmind.cloud/** |

## 2. 게임 개요

### 2-1. 세계관 — 기만당한 구원

지상 인류는 환경 오염과 자원 고갈로 멸망의 카운트다운을 기다리고 있습니다. 통치 기구
'상부 기조국'은 인류 구원이라는 명분으로 '심연 보완 계획'을 발표하고, 순백의 제복을
입힌 요원들을 지하 9,999층까지 뚫린 거대 구조물 '디스토픽 어비스'로 밀어 넣습니다.

**구원은 기만입니다.** 9,999층 '제로 프론티어'에 잠든 '제1원초급 코어'는 지상을 파괴한
재앙의 근원이자 모든 타락의 흑막입니다. 기조국은 요원들이 하강하며 기압·방사선·흑염
폭풍에 인간성을 잃을 것을 알면서도 이들을 제물로 던졌습니다.

**문제는 심연이 내려가는 자를 매혹적으로 바꾼다는 것입니다.** 깊이 들어갈수록 도덕과
이성이 녹아내리고, 요원은 심연의 마력을 받아들여 각성체로 거듭납니다. 강해진다는 것은
곧 인간의 존엄을 잃어 간다는 대가를 뜻합니다.

층은 1,000층씩 10개 페이즈로 나뉩니다 — 표층 지각의 달콤한 환청 지대에서 시작해
고열 온천, 체렌코프 방사선 지대, 흑염 이온 폭풍, 몽마의 독안개, 영원 빙하, 중력
챔버, 시공간 환영, 에테르 승천 경계를 지나 제로 프론티어의 최종 제단에 닿습니다.

### 2-2. 타락도 — 이 게임의 중심 장치

깊이와 '심연의 선택' 수용 횟수가 타락도(0~100)를 올리고, 타락도는 **공격력 배율**로
직접 돌아옵니다. 강해지는 유일한 지름길이 곧 파멸의 게이지가 되도록 설계했습니다.

| 단계 | 타락도 | ATK 배율 | 서사적 상태 |
|------|-------|---------|------------|
| 일반 | 0 ~ 29 | ×1.00 | 지상의 맹세와 이성을 유지하려 애씁니다 |
| **각성** | **30 ~ 49** | **×1.15** | 심연의 힘에 눈을 뜹니다 — **타락 스킬이 해금됩니다** |
| 중간타락 | 50 ~ 69 | ×1.30 | 도덕관념이 흐려지고 파괴의 쾌락을 깨닫습니다 |
| 타락 | 70 ~ 99 | ×1.50 | 인간성을 포기하고 흑마력을 제어합니다 — **엔딩 B 확정선** |
| 완전타락 | 100 | ×2.00 | 제1코어의 에너지를 역으로 집어삼킨 상태입니다 |

**깊이만으로는 60까지만 오릅니다.** 나머지 40은 '심연의 선택'을 수용한 횟수가 채웁니다
— 즉 **완전타락은 방치로 닿을 수 없고, 플레이어가 스스로 그 대가를 선택해야** 합니다.

### 2-3. 심연의 선택 — 두 개의 버튼

보스를 클리어하면 모달이 뜹니다.

> **심연의 선택**
> 보스가 남긴 심연의 마력이 스며든다.
> 받아들이면 강해지지만, 타락도가 오른다.
>
> `[ 수용한다 (+10 타락) ]`   `[ 거부한다 ]`

이 게임에서 **"안전하게 갈지 강해질지"는 이 한 축으로 정해집니다.** 수용하면 공격력이
즉시 붙고, 결말은 B로 기웁니다.

### 2-4. 듀얼 엔딩 — 타락도 70이 갈림선

9,999층 제로 프론티어에 도달했을 때, 쌓아온 타락도가 결말을 결정합니다.

| | 조건 | 결말 |
|---|---|---|
| **엔딩 A — 성녀의 속죄** | 타락도 0 ~ 69 | 타락의 마력을 극한까지 제어한 그녀는 제1코어의 폭주를 정화하고, 스스로를 심연 깊은 곳에 봉인했다. 지상은 그녀의 이름을 기억하지 못한다. |
| **엔딩 B — 심연의 여신** | 타락도 70 ~ 100 | 그녀는 제1코어와 융합했다. 심연도, 지상도, 이제 그녀의 것이다. 구원은 왔다 — 그녀가 정의한 방식으로. |

### 2-5. 두 개의 모드 — 같은 세계, 같은 캐릭터

| 모드 | 무엇 | 승패 |
|------|------|------|
| **심연 하강** (싱글) | 층을 계속 내려가는 방치 RPG입니다. 위로 스와이프하면 가속됩니다 | 9,999층 도달 → 엔딩 A/B |
| **대전** (PvP) | 화면 상/하 2분할. 같은 던전·같은 몬스터를 상대와 **동시에** 내려갑니다 | 중앙 게이지를 상대 쪽으로 밀면 승리 |

두 모드는 같은 캐릭터와 같은 전투 규칙을 공유합니다. **싱글에서 키운 강화·타락도·카드가
그대로 대전 전력이 됩니다** — 방치로 쌓은 성장이 사람과의 승부에서 값을 갖도록
구성했습니다.

### 2-6. 캐릭터 4종

| 이름 | 역할 | 색 | 무기 |
|------|------|-----|------|
| **리제** | 근접 딜러 | 적색 | 대검 |
| **노라** | 탱커 | 순백 | 활 |
| **실비아** | 마법 딜러 | 보라 | 지팡이 |
| **클로에** | 서포터 | 핑크 | 쌍단검 |

선택한 캐릭터로 하강합니다. 캐릭터 원화와 모션은 전부 AI 생성 파이프라인으로
만들었으며, 그 과정은 제출물 ④ AI 활용 기술 문서에 정리했습니다.

### 2-7. 카드 수집 — 감상용이 아니라 전투력입니다

| | |
|---|---|
| 카드함 | **35장** (캐릭터별 5장). 등급은 일반 · 희귀 · 전설 |
| 얻는 방법 | **보스 층 클리어**(10층마다 1장) · **심연석 가챠**(10 심연석) · **대전 승리**(반드시 1장) |
| 전투 효과 | 모은 **장수**가 팀 공격력으로 (**장당 +2%, 최대 ×2**). 싱글·대전 공용 |
| 보는 곳 | 타이틀 우측 상단 **카드함** — `카드함 12/35` 격자 |

카드는 보스를 잡을 때마다 **미획득 카드 중에서 반드시 하나** 나오도록 했습니다. 확률로
주지 않은 이유는 명확합니다 — 보스를 이긴 보상이 "없음"이면 그것은 보상이 아닙니다.

## 3. 플레이 방법

### 3-1. 목표

| 모드 | 목표 |
|------|------|
| **심연 하강** | 9,999층 제로 프론티어에 도달해 엔딩 A/B를 확인합니다. 하강 중 보스를 격파하고, **골드로 강화 4종을 올리고 타락도를 조율하며 카드를 모으는** 것이 핵심 루프입니다. |
| **대전** | 중앙 게이지를 상대 쪽으로 밀어붙입니다. 게이지가 0.8에 닿으면 즉시 승리하고, 120초가 지나면 게이지가 기운 쪽이 이깁니다. |

**대전에서 몬스터는 위협이 아니라 자원입니다.** 지는 이유는 하나 — **상대가 몬스터를
나보다 빨리 잡는 것**입니다. 그래서 대전은 서로를 때리는 싸움이 아니라 **속도 경쟁**이
됩니다.

### 3-2. 조작 — 터치 1점

드래그·롱프레스·핀치가 없습니다. 세로 화면을 한 손으로 든 채 전부 조작할 수 있습니다.

| 조작 | 무엇이 일어나는가 |
|------|------------------|
| **위로 스와이프** | 하강 가속 — 층 전환을 건너뛰고 3초간 팀 공격력 ×1.5 |
| **화면 하단 스킬 칸 탭** | 스킬 시전 — 공격 스킬과 타락 스킬, 대전에서는 방해 스킬까지 |
| **AUTO 배지 탭** | 전투 자동화 ON / OFF |
| **강화 줄 위로 드래그** | 강화 시트 — 공격력 · 공격 속도 · 골드 획득 · 스킬 위력 |
| **카드함 탭** | 모은 카드 35장을 격자로 확인 |

**방치해도 굴러가지만, 손을 쓰면 두 배 가까이 빨라집니다.** 실측으로 총딜의 83%가
스킬에서 나옵니다 — 가만히 두면 평균 334 dps, 쿨다운마다 누르면 595 dps입니다.

**AUTO를 끄면 완전히 멈춥니다.** 캐릭터도 데미지도 함께 멈추고, 그 순간부터 진행은
직접 누른 스킬만으로 이뤄집니다. 방치형이면서도 "내가 조작하는 게임"으로 전환할 수
있는 스위치로 넣었습니다.

### 3-3. 코어 루프

```text
하강 (위로 스와이프 ↑)
   → 전투 (스킬 탭)
   → 보상 (골드 · 심연석 · 카드)
   → 강화 4종 구매 · '심연의 선택'으로 타락도 조율
   ↺ 더 깊은 층으로 — 배율이 곱해진 채 더 강한 적에게
```

| 층 | 종류 | 보상 |
|------|------|------|
| 1 ~ 9 등 | 잡몹 (내려갈수록 다른 종류) | 골드 |
| **10, 20, 30 …** | **미니보스** | 심연석 3 + **카드 1장** + '심연의 선택' |
| **100, 200 …** | **네임드 대보스** | 심연석 20 + 카드 1장 |
| **1,000, 2,000 …** | **초월체** (페이즈 전환) | 연출 + 배경·몬스터 교체 |

- 층 클리어를 8초 안에 이어 가면 **콤보**가 쌓여 골드 배율이 최대 ×3까지 오릅니다.
- 접속하지 않은 시간도 계산합니다 — 최대 **120층**분 방치 보상이 들어옵니다.
- 진행은 브라우저에 자동 저장됩니다. 계정도 로그인도 필요 없습니다.

### 3-4. 대전 한 판의 흐름

```text
매칭(사람 우선 5초 대기 → 없으면 AI) → VS 인트로
   → 전투 (스킬 칸을 쿨마다 연타)
   → 게이지 0.8 도달 또는 120초 경과 → 결과(승리 시 카드 1장) → 재대전
```

실측 한 판은 **쿨다운마다 스킬을 쓰면 50~58초에 승리**로 끝납니다. 방치하면 120초까지
끌려가 박빙으로 겨우 이깁니다 — **조작이 승부를 만드는 폭**이 그만큼입니다.

## 4. 첫 5분 가이드 (심사자용)

아래 내용은 **전부 지금 링크에서 그대로 동작합니다.** 페이스는 **3분에 30층, 10분에
100층**입니다. 시간이 없으시면 **1 → 3 → 6**만으로도 이 게임의 핵심이 보입니다.

1. 타이틀에서 **[심연 하강]** — 프롤로그 3장을 넘기면 바로 전투가 시작됩니다.
2. **화면 중앙을 위로 밀어 주십시오** — 하강이 가속되고 3초간 팀 공격력 ×1.5, 콤보가
   붙습니다.
3. **화면 아래 스킬 칸을 쿨이 도는 대로 눌러 주십시오** — **여기서 딜의 100%가
   나옵니다.** 방치 화면과 조작 화면의 속도 차이가 바로 보입니다.
4. **50층에서 '심연의 선택'이 뜹니다** — 수용하면 타락도 +10, 공격력 배율이 ×1.00 →
   ×1.15로 붙습니다. 이 선택의 누적이 엔딩을 가릅니다.
5. **강화 줄을 위로 끌어 주십시오** — 강화 4종과 `카드 뽑기`가 여기 있습니다. 보스는
   10층마다 나오므로 **40층이면 심연석 12개**로 첫 뽑기가 됩니다.
6. **대전은 이 링크로 바로 들어옵니다** — https://abyss.agenticmind.cloud/?unlock=pvp
   상대가 없으면 5초 뒤 AI가 붙으므로 언제 접속하셔도 한 판이 성립합니다.

## 5. 실행 방법

### 5-1. 링크 클릭만 하면 됩니다 — 설치 없음

| | |
|---|---|
| **플레이 링크** | **https://abyss.agenticmind.cloud/** |
| 권장 환경 | **모바일 세로** (iOS Safari / Android Chrome). PC 브라우저도 정상 동작합니다 |
| 계정 · 로그인 | 없습니다 |
| 설치 · 유료 라이선스 | 없습니다 |

세로 전용이므로 PC에서는 좌우에 검은 여백(레터박스)이 생기는 것이 정상입니다. 디자인
해상도는 720 × 1280입니다.

### 5-2. 대전 바로 보기 링크

대전은 **싱글 100층에서 열리도록 구성해 두었습니다.** 대전은 싱글에서 키운 캐릭터로
싸우기 때문에, 성장 없이 들어가면 무엇을 눌러도 이길 수 없기 때문입니다.

**심사 과정에서 그 100층은 10분입니다.** 그래서 잠금을 바로 여는 링크를 함께
준비했습니다.

| | |
|---|---|
| 해제 링크 | **https://abyss.agenticmind.cloud/?unlock=pvp** |
| 무엇이 열리나 | 타이틀의 `대전` 버튼 (`대전 · 100층` → `대전 시작`) |

진행도는 손대지 않습니다 — 층수·강화·골드는 저장값 그대로이므로, 심사자께서 보시는
대전도 **실제 플레이와 같은 규칙**으로 돌아갑니다.

### 5-3. 소스에서 직접 실행

```bash

cd nan2026-sin-dive/01-build-and-source
npm install
npm run dev            # http://localhost:5173
```

빌드와 검증:

```bash

npm test               # 자동 테스트 1,657개
```
