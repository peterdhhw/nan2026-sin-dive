# 1. 플레이 가능한 빌드 및 소스 코드

**요구 사항**: 웹(브라우저 실행) 또는 모바일 앱(APK·테스트 링크) + **전체 소스**
**제출 형식**: GitHub Pages (링크)

## 들어갈 것

- [ ] 전체 소스 코드 (`src/`, `tests/`, `tools/`, `public/`, 빌드 설정)
- [ ] GitHub Pages로 서브되는 정적 빌드 산출물 또는 Pages 배포 워크플로
- [ ] 로컬 실행 방법 (`npm install` → `npm run dev`) 및 빌드 방법
- [ ] Pages 링크를 루트 [`README.md`](../README.md)의 링크 표에 기재

## 주의

- **비밀값은 커밋하지 않는다.** PvP 서버(AppSync) API 키는 `.env.local`에만 두고
  `.gitignore`로 막는다. 이 레포는 정리 후 **public**으로 전환하므로 과거 커밋까지
  전부 열린다 — 키가 한 번이라도 커밋되면 히스토리 재작성 없이는 회수할 수 없다.
- Pages는 정적 호스팅이다. PvP는 외부 AppSync를 호출하므로 키 없이 빌드하면
  싱글 모드만 동작한다 — 무엇이 되고 무엇이 안 되는지 실행 방법에 명시한다.
